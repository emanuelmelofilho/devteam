# Módulo de notificações

## v0.2.0

- Notifica o usuário que iniciou a transição quando uma atividade entra em **Em andamento**.
- Notifica o usuário quando uma atividade chega a **Publicado**, considerada concluída.
- Mantém as notificações no banco, com contador de não lidas e ação para marcar todas como lidas.
- Solicita permissão para alertas nativos do navegador ao abrir a central.
- Envia os mesmos eventos por WhatsApp quando a integração estiver configurada.
